Rainbow Chaos

+

Every keystroke changes the page color to a random hue. Type fast and watch it strobo. No way to stop it without refreshing.

// hsl(Math.random() * 360, 100%, 50%)

+

Your Learning Path

Beginner → Advanced

This is how you go from zero to hero.

Phase 1: Beginner 🟢

What you'll learn:

  • HTML basics (elements, structure)
  • CSS styling (colors, fonts, layout)
  • JavaScript basics (variables, functions)
  • Events (clicks, form submissions)

You'll build:

  • Your first website
  • A simple game
  • A working form
  • Something you're proud of

⏱️ 2-4 weeks to get here

Phase 2: Intermediate 🟡

What you'll learn:

  • More complex JavaScript
  • APIs (fetch, async/await)
  • Local storage & databases
  • Responsive design & mobile

You'll build:

  • A dashboard with data
  • A social-style app
  • Something with real user features
  • A mini app you can show employers

⏱️ 1-3 months from beginner

Phase 3: Advanced 🔴

What you'll learn:

  • Frameworks (React, Vue)
  • Backend basics (Node.js)
  • Real databases (Firebase)
  • Deployment & DevOps

You'll build:

  • A full-stack app
  • Something with login
  • A real product
  • Your startup idea

⏱️ 3-6 months from intermediate
